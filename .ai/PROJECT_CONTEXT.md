## Resumo Atual

O ERP Toolkit é uma plataforma de ferramentas para consultores, analistas e desenvolvedores de ERP.

Estado atual:

- Sprint 1 concluída.
- Sprint 1.1 de refinamento de UX do JSON Formatter concluída.
- Frontend em React, TypeScript, Vite e Tailwind CSS.
- Backend em Python com FastAPI.
- SQLite configurado inicialmente.
- Frontend em `http://localhost:5183`.
- Backend em `http://localhost:8000`.
- Paleta principal azul.
- JSON Formatter completo.
- Base64, UUID Generator, Password Generator e SQL Formatter em versão inicial.
